# 警惕儿童矮身材、性早熟！首都儿研所专家坐诊烟台毓璜顶医院，面对面为您答疑解惑

> 更新时间：2026-09-17 (UTC+8)

随着生活水平提升，儿童平均身高逐步增长，但家长对孩子身高的期待值也随之提高，“担心孩子长不高”已成为许多家庭的焦虑点。与此同时，儿童性早熟、生长发育紊乱等问题也困扰着不少家长。

为切实解决家长困惑，助力儿童健康成长，医院特邀首都儿科研究所生长发育研究室孙淑英主任，于9月21日坐诊答疑，与医院儿科内分泌专家强强联合，为孩子的生长发育保驾护航。

**家长常见困惑**

**专家为您解答**

•身高之谜：生长激素不缺乏却严重发育迟缓、父母身高正常孩子却偏矮、不确定孩子是否“晚长”；

•发育之惑：孩子出现复杂性性早熟、青春期发育延迟或紊乱；

•遗传之疑：孩子存在特纳综合征、普拉德-威利综合征等遗传/代谢/染色体异常，影响生长发育；

•治疗之困：不清楚生长发育相关治疗药物的安全性与疗效；

•多系统问题：孩子身高偏矮的同时，还伴有骨骼、神经、营养或心理行为异常。

**看看孩子身高达标了吗？**

**活动详情**

1. 活动内容

•儿童生长发育专业评估；

•矮小症、性早熟个性化治疗方案制定（早发现、早干预，避免终身遗憾）。

2. 活动对象（3-16岁儿童，符合以下任一情况即可参与）

•班级座位长期靠前、身高明显低于同龄孩子，且儿童期每年长高不足5厘米；

•存在性早熟迹象：女孩7.5岁前乳房发育或10岁前月经来潮，男孩9岁前睾丸/阴茎明显发育、10-12岁提前蹿个/长喉结/变声；

•早产儿、小于胎龄儿、高危儿，且存在发育异常落后或遗传代谢问题；

•家长对孩子身高有较高期望，孩子有明确长高需求。

3. 活动时间

2025年9月21日（周日）上午8:00-11:30

4. 活动地点

烟台毓璜顶医院总院东区一楼儿内科门诊8诊室

5. 报名方式

微信扫描报名二维码（请准确填写信息，限30人，报满即止）

温馨提示

1.参与活动者，请于9月21日上午到医院现场挂李坤霞主任门诊号，按挂号顺序就诊；

2.首都儿研所孙淑英主任仅坐诊半天，且仅接诊已完成所有相关检查的患者；
