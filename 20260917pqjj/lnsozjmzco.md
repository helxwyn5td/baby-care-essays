# 我一直咳嗽，是得了新冠肺炎吗？

> 更新时间：2026-09-17 (UTC+8)

3种传播途径都与

咳嗽产生的飞沫有关

****

不焦虑 好心态

新冠肺炎主要经呼吸道飞沫和接触传播，气溶胶等传播途径尚待明确，但这3种传播途径都与咳嗽、打喷嚏时产生的飞沫有关，病毒或细菌会搭着这些飞沫扩散。

干咳是新冠肺炎主要表现之一

****

不焦虑 好心态

发热、乏力、干咳是新冠肺炎主要的临床表现。如果近期接触过可疑传染源,出现发热、咳嗽、气促等急性呼吸道感染症状,需及时就医。

儿童咳喘

与多种因素有关

****

不焦虑 好心态

出现发热、乏力、干咳症状不一定就是感染了新冠病毒,尤其儿童咳喘通常与病毒、细菌感染、居住环境、空气污染、二手烟等因素都有关,不能简单以症状判断是否为新冠病毒感染。

普通病人不宜

随意使用抗生素

不焦虑 好心态

如果出现发热、咳嗽、鼻塞、打喷嚏等症状,请自觉减少与他人接触,出门戴好口罩。对于普通病人而言,不宜在咳嗽时随意使用抗生素。

咳嗽时不建议用手捂住口鼻

不焦虑 好心态

咳嗽或打喷嚏时,要用纸巾或手肘捂住口鼻,不建议用手捂口鼻,双手的严密性不及衣袖。

没洗手不要揉眼睛

****

不焦虑 好心态

咳嗽或打喷嚏时用过的纸巾要扔入垃圾桶,然后彻底清洗双手。不要没洗手就揉眼睛或接触粘膜的部位。

肺炎只是引起咳嗽

的其中一种原因

****

不焦虑 好心态

咳嗽本身不会引起肺炎，相反是肺炎引起了咳嗽。咳嗽只是症状，它可以由很多原因导致，包括食物呛到、感冒、气胸等，肺炎只是其中一种原因。

春天需警惕

花粉等过敏原

不焦虑 好心态

春天一到,空气中飘荡的花粉、霉菌等过敏原增多,一旦进入呼吸道就可能引起干咳、嗓子痒、打喷嚏等过敏症状,严重的还可能出现剧烈咳嗽。

减少外出是有效的预防手段

不焦虑 好心态

对于过敏引起的久咳不愈,可以在呼吸科医生指导下使用抗过敏药物。但最好的办法还是做好预防,如减少外出、定期换床单、清洁沙发地毯等,尽量避免接触过敏原。
